# SQL Cheatsheet

Цей файл містить усі SQL-команди, які ми вивчили під час навчання, з короткими поясненнями.

## 1. Створення таблиці (CREATE TABLE)
Створює нову таблицю в базі даних.

-- Create a new table for electronics
CREATE TABLE Electronics(
    Id INTEGER PRIMARY KEY AUTOINCREMENT,
    Name TEXT NOT NULL,
    Category TEXT,
    Price REAL,
    InStock INTEGER
);

Ключові слова та типи даних:
    CREATE TABLE — команда для створення нової таблиці.
    INTEGER — тип даних для зберігання цілих чисел (1, 2, 100).
    TEXT — тип даних для зберігання тексту (літери, слова).
    REAL — тип даних для зберігання чисел із плаваючою комою (1.5, 999.99).
    PRIMARY KEY — обмеження, яке робить стовпчик унікальним ідентифікатором рядка. Значення в цьому стовпчику не можуть повторюватися.
    AUTOINCREMENT — властивість, яка змушує базу даних автоматично збільшувати значення на 1 при додаванні нового рядка (1, 2, 3...).
    NOT NULL — обмеження, яке забороняє залишати поле порожнім. Значення обов'язково має бути вказане.

## 2. Додавання даних (INSERT)
Додає новий рядок (запис) у таблицю.
Ключові слова та синтаксис:
    INSERT INTO — команда для додавання нового запису в таблицю.
    (Стовпчик1, Стовпчик2, ...) — список колонок, які ми заповнюємо. Ми можемо пропустити стовпчик Id, оскільки він має AUTOINCREMENT і заповниться автоматично.
    VALUES — ключове слово, яке вказує на початок списку значень.
    (Значення1, Значення2, ...) — самі дані. Важливо: значення мають йти в тому ж порядку, що й стовпчики в дужках вище.
Текст береться в одинарні лапки '...'.
Числа пишуться без лапок.

## 3. Вибірка даних (SELECT)
Читає дані з таблиці. Найчастіше використовувана команда.
    SELECT — команда "вибрати".
    * (зірочка) — означає "всі стовпчики". Якщо ти хочеш вибрати не всі, а конкретні (наприклад, тільки назву і ціну), ти перелічуєш їх через кому: SELECT Name, Price.
    FROM — вказує, з якої таблиці брати дані.

## 4. Фільтрація даних (WHERE)
Дозволяє вибрати лише ті рядки, які відповідають певній умові. Використовується разом із `SELECT`.
Ключові слова та синтаксис:
    WHERE — ключове слово, яке починає умову фільтрації. Воно йде після FROM.
    Умова — логічний вираз, який перевіряється для кожного рядка.
    Оператори порівняння:
        = — дорівнює (для тексту використовуй лапки: WHERE Category = 'Ноутбуки').
        > — більше.
        < — менше.
        >= — більше або дорівнює.
        <= — менше або дорівнює.
        <> або != — не дорівнює.
    Логічні оператори (для складних умов):
        AND — і (обидві умови мають бути істинними).
        OR — або (хоча б одна умова має бути істинною).

## 5. Сортування даних (ORDER BY)
Дозволяє впорядкувати результати запиту за одним або кількома стовпчиками.
Ключові слова та синтаксис:
    ORDER BY — ключове слово, яке вказує, за яким стовпчиком сортувати. Воно йде після WHERE (якщо він є) або після FROM.
    ASC (ascending) — сортування за зростанням (від меншого до більшого, від А до Я). Це типове значення, тому його можна не писати.
    DESC (descending) — сортування за спаданням (від більшого до меншого, від Я до А).

## 6. Агрегатні функції
Це функції, які виконують обчислення над набором значень і повертають одне єдине значення (число).
Основні агрегатні функції:
    COUNT(*) — рахує кількість рядків у таблиці (або в групі).
    SUM(стовпчик) — обчислює суму значень у стовпчику (тільки для чисел).
    AVG(стовпчик) — обчислює середнє арифметичне значень у стовпчику (тільки для чисел).
    **Деталі по SUM та AVG:**
    *   `SUM(стовпчик)` — додає всі значення в стовпчику. Використовується тільки для чисел. Наприклад, `SUM(Price)` поверне загальну вартість усіх товарів.
    *   `AVG(стовпчик)` — обчислює середнє арифметичне (сума поділена на кількість). Також тільки для чисел. Наприклад, `AVG(Price)` поверне середню ціну товару.
    MIN(стовпчик) — знаходить мінімальне значення в стовпчику.
    MAX(стовпчик) — знаходить максимальне значення в стовпчику.
    **Деталі по MIN та MAX:**
    *   `MIN(стовпчик)` — знаходить найменше значення в стовпчику.
    *   `MAX(стовпчик)` — знаходить найбільше значення в стовпчику.
    *   Вони працюють не тільки з числами, а й з текстом (наприклад, `MIN(Name)` знайде першу назву за алфавітом) та датами.
Важливо: Агрегатні функції повертають один рядок з результатом, навіть якщо в таблиці тисячі рядків. Вони "згортають" усі дані в одне число.

## 7. Групування даних (GROUP BY)
Дозволяє групувати рядки з однаковими значеннями в один рядок результату. Зазвичай використовується разом з агрегатними функціями (`COUNT`, `SUM`, `AVG`, `MIN`, `MAX`).
Ключові слова та синтаксис:
    GROUP BY — ключове слово, яке вказує, за яким стовпчиком групувати. Воно йде після WHERE (якщо він є) і перед ORDER BY.
    SELECT Category, COUNT(*) — у запиті ми вибираємо сам стовпчик, за яким групуємо (Category), і агрегатну функцію (COUNT(*)), яка рахує кількість рядків у кожній групі.
Важливо: якщо ти використовуєш GROUP BY, то в SELECT ти можеш вибирати лише ті стовпчики, за якими групуєш, або агрегатні функції. Не можна вибрати Name, бо в одній категорії може бути багато різних назв.

## 8. З'єднання таблиць (JOIN)
Дозволяє об'єднувати дані з двох або більше таблиць в один результат на основі спільного стовпчика (зазвичай це первинний ключ однієї таблиці та зовнішній ключ іншої).
Ключові слова та синтаксис:
    JOIN (або INNER JOIN) — команда, яка з'єднує дві таблиці.
    ON — ключове слово, яке вказує умову з'єднання. Тобто, за яким стовпчиком ми пов'язуємо таблиці.
    Orders.CustomerId = Customers.Id — це і є умова. Ми кажемо базі: "з'єднай рядок з таблиці Orders з таким рядком з таблиці Customers, де значення CustomerId в Orders дорівнює значенню Id в Customers".
    Customers.Name — звернення до стовпчика Name з таблиці Customers. Крапка розділяє назву таблиці та назву стовпчика.

## 9. Різновиди JOIN (LEFT JOIN)
`LEFT JOIN` (ліве з'єднання) показує **всі рядки з лівої таблиці** та ті, що збігаються, з правої. Якщо для рядка з лівої таблиці немає пари в правій, то в результаті для стовпчиків правої таблиці буде `NULL` (порожнеча).
    LEFT JOIN — команда, яка з'єднує дві таблиці, але головною вважається таблиця, яка стоїть у FROM (ліва). Всі її рядки будуть у результаті.
    NULL — спеціальне значення в SQL, яке означає "порожнеча" або "невідомо". Воно з'являється, коли для рядка немає пари в іншій таблиці.

## 10. Різновиди JOIN (RIGHT JOIN)
`RIGHT JOIN` (праве з'єднання) — це дзеркальне відображення `LEFT JOIN`. Він показує **всі рядки з правої таблиці** (тієї, що стоїть після `JOIN`), навіть якщо для них немає пари в лівій. Якщо для рядка з правої таблиці немає пари в лівій, то в результаті для стовпчиків лівої таблиці буде `NULL`.
    RIGHT JOIN — команда, яка з'єднує дві таблиці, але головною вважається таблиця, яка стоїть після JOIN (права). Всі її рядки будуть у результаті.
Порядок написання умови ON (ліворуч-праворуч) не має значення, як і в LEFT JOIN.

## 11. Аліаси (AS)
Дозволяє давати тимчасові імена стовпчикам або таблицям у результаті запиту. Це робить результат зрозумілішим і полегшує написання складних запитів.
    AS — ключове слово, яке вказує на початок аліасу.
    Стовпчик AS НовеІм'я — після стовпчика пишемо AS і нову назву (без лапок, якщо це одне слово).
    Аліаси для таблиць: також можна давати таблицям короткі імена, щоб не писати повну назву щоразу. Наприклад: FROM Electronics AS e, і далі звертатися e.Name замість Electronics.Name. Це особливо зручно, коли таблиць багато.
**Важливо про пробіли в аліасах:**
*   Якщо назва аліасу містить пробіли (наприклад, `Product Name`), її обов'язково треба брати в подвійні лапки: `AS "Product Name"`.
*   Без лапок база даних сприйме пробіл як розділювач і видасть помилку.
*   У реальній роботі краще уникати пробілів і використовувати `CamelCase` (наприклад, `ProductName`) — це зручніше для SQL та C#.

**Аліаси для таблиць:**
Можна давати таблицям короткі імена, щоб не писати повну назву щоразу. Це особливо зручно, коли таблиць багато.
    FROM Electronics AS e — ми кажемо: "таблиця Electronics тепер має псевдонім e".
Далі в SELECT та інших частинах запиту ми можемо звертатися до неї як e.Name, e.Price замість Electronics.Name, Electronics.Price. Це економить час і робить код чистішим.

## 12. Оновлення даних (UPDATE)
Дозволяє змінювати значення в існуючих рядках таблиці.
    UPDATE — команда для оновлення даних.
    НазваТаблиці — таблиця, яку ми оновлюємо.
    SET — ключове слово, після якого вказуємо, який стовпчик і на яке нове значення змінюємо. Можна змінювати кілька стовпчиків через кому.
    WHERE — критично важлива умова! Вона вказує, які саме рядки треба оновити. Якщо забути WHERE, оновляться ВСІ рядки в таблиці! Це одна з найнебезпечніших помилок у SQL.

## 13. Видалення даних (DELETE)
Дозволяє видаляти існуючі рядки з таблиці.
    DELETE FROM — команда для видалення рядків.
    НазваТаблиці — таблиця, з якої ми видаляємо.
    WHERE — критично важлива умова! Вона вказує, які саме рядки треба видалити. Якщо забути WHERE, видаляться ВСІ рядки в таблиці! Це ще небезпечніше, ніж у UPDATE, бо дані зникають назавжди.
