# SQL Cheatsheet

Цей файл містить усі SQL-команди, які ми вивчили під час навчання, з короткими поясненнями.

## 1. Створення таблиці (CREATE TABLE)
Створює нову таблицю в базі даних.

-- Create a new table for electronics
CREATE TABLE Electronics(
    Id INTEGER PRIMARY KEY AUTOINCREMENT,
    Name TEXT NOT NULL,
    Category TEXT,
    Price REAL,
    InStock INTEGER
);

Ключові слова та типи даних:
    CREATE TABLE — команда для створення нової таблиці.
    INTEGER — тип даних для зберігання цілих чисел (1, 2, 100).
    TEXT — тип даних для зберігання тексту (літери, слова).
    REAL — тип даних для зберігання чисел із плаваючою комою (1.5, 999.99).
    PRIMARY KEY — обмеження, яке робить стовпчик унікальним ідентифікатором рядка. Значення в цьому стовпчику не можуть повторюватися.
    AUTOINCREMENT — властивість, яка змушує базу даних автоматично збільшувати значення на 1 при додаванні нового рядка (1, 2, 3...).
    NOT NULL — обмеження, яке забороняє залишати поле порожнім. Значення обов'язково має бути вказане.

## 2. Додавання даних (INSERT)
Додає новий рядок (запис) у таблицю.
Ключові слова та синтаксис:
    INSERT INTO — команда для додавання нового запису в таблицю.
    (Стовпчик1, Стовпчик2, ...) — список колонок, які ми заповнюємо. Ми можемо пропустити стовпчик Id, оскільки він має AUTOINCREMENT і заповниться автоматично.
    VALUES — ключове слово, яке вказує на початок списку значень.
    (Значення1, Значення2, ...) — самі дані. Важливо: значення мають йти в тому ж порядку, що й стовпчики в дужках вище.
Текст береться в одинарні лапки '...'.
Числа пишуться без лапок.

## 3. Вибірка даних (SELECT)
Читає дані з таблиці. Найчастіше використовувана команда.
    SELECT — команда "вибрати".
    * (зірочка) — означає "всі стовпчики". Якщо ти хочеш вибрати не всі, а конкретні (наприклад, тільки назву і ціну), ти перелічуєш їх через кому: SELECT Name, Price.
    FROM — вказує, з якої таблиці брати дані.

## 4. Фільтрація даних (WHERE)
Дозволяє вибрати лише ті рядки, які відповідають певній умові. Використовується разом із `SELECT`.
Ключові слова та синтаксис:
    WHERE — ключове слово, яке починає умову фільтрації. Воно йде після FROM.
    Умова — логічний вираз, який перевіряється для кожного рядка.
    Оператори порівняння:
        = — дорівнює (для тексту використовуй лапки: WHERE Category = 'Ноутбуки').
        > — більше.
        < — менше.
        >= — більше або дорівнює.
        <= — менше або дорівнює.
        <> або != — не дорівнює.
    Логічні оператори (для складних умов):
        AND — і (обидві умови мають бути істинними).
        OR — або (хоча б одна умова має бути істинною).

## 5. Сортування даних (ORDER BY)
Дозволяє впорядкувати результати запиту за одним або кількома стовпчиками.
Ключові слова та синтаксис:
    ORDER BY — ключове слово, яке вказує, за яким стовпчиком сортувати. Воно йде після WHERE (якщо він є) або після FROM.
    ASC (ascending) — сортування за зростанням (від меншого до більшого, від А до Я). Це типове значення, тому його можна не писати.
    DESC (descending) — сортування за спаданням (від більшого до меншого, від Я до А).

## 6. Агрегатні функції
Це функції, які виконують обчислення над набором значень і повертають одне єдине значення (число).
Основні агрегатні функції:
    COUNT(*) — рахує кількість рядків у таблиці (або в групі).
    SUM(стовпчик) — обчислює суму значень у стовпчику (тільки для чисел).
    AVG(стовпчик) — обчислює середнє арифметичне значень у стовпчику (тільки для чисел).
    **Деталі по SUM та AVG:**
    *   `SUM(стовпчик)` — додає всі значення в стовпчику. Використовується тільки для чисел. Наприклад, `SUM(Price)` поверне загальну вартість усіх товарів.
    *   `AVG(стовпчик)` — обчислює середнє арифметичне (сума поділена на кількість). Також тільки для чисел. Наприклад, `AVG(Price)` поверне середню ціну товару.
    MIN(стовпчик) — знаходить мінімальне значення в стовпчику.
    MAX(стовпчик) — знаходить максимальне значення в стовпчику.
    **Деталі по MIN та MAX:**
    *   `MIN(стовпчик)` — знаходить найменше значення в стовпчику.
    *   `MAX(стовпчик)` — знаходить найбільше значення в стовпчику.
    *   Вони працюють не тільки з числами, а й з текстом (наприклад, `MIN(Name)` знайде першу назву за алфавітом) та датами.
Важливо: Агрегатні функції повертають один рядок з результатом, навіть якщо в таблиці тисячі рядків. Вони "згортають" усі дані в одне число.
